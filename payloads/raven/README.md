# RZUSBSTICK / AVR Raven

The Atmel RZUSBSTICK (AT86RF230 2.4 GHz 802.15.4 radio + AT90USB1287 USB MCU) is the classic KillerBee Zigbee/802.15.4 sniffer and frame injector. It is flashed over USB DFU with `dfu-programmer` (target part `at90usb1287`, sequence erase -> flash -> reset) once the AT90USB1287 is in DFU mode — hold the HWB button while plugging the stick in so it enumerates as the Atmel DFU bootloader (VID:PID 03EB:2FFB); avrdude with a hardware JTAG programmer (AVR Dragon) is the fallback. One firmware option is provided: **flash-killerbee** installs the KillerBee `kb-rzusbstick-006.hex` image (from riverloopsec/killerbee, with DFU + native bootloader support) so the stick runs as a KillerBee Rx/Tx interface for tools like `zbid`, `zbstumbler`, `zbdump`, and `zbwireshark`.
