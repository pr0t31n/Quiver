# Qorvo DWM3000EVB

The Qorvo (Decawave) DWM3000EVB is a DW3000 Ultra-Wideband (IEEE 802.15.4z HRP UWB) Arduino/ST shield with **no onboard microcontroller** — the DW3000 transceiver is driven over SPI by a host MCU, which in the Quiver rig is the STM32 Nucleo-F429ZI. Because the shield cannot run code by itself, "flashing the DWM3000EVB" means writing the Qorvo DW3000 example firmware to the **host Nucleo** over the Nucleo's onboard ST-Link (`st-flash write <fw.bin> 0x08000000`, with STM32CubeProgrammer as a fallback for `.hex`/`.elf`). One firmware option is provided — `qorvo-ranging`, the DW3000 two-way-ranging / Nearby-Interaction example (full UWB Rx + Tx). Qorvo's DW3000 STM32/Nucleo SDK is behind an account-registration wall, so the image is operator-supplied: set `QUIVER_DWM3000_FW=/path`, `QUIVER_DWM3000_FW_URL=<direct URL>`, or drop the image into `firmware/dwm3000evb/`; prepare verifies the flasher and image are present before the single confirmation and aborts beforehand if either is missing.
