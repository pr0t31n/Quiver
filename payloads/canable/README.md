# CANable (USB-CAN)

The CANable is an open-source USB-to-CAN adapter built on an STM32 microcontroller (CANable 1.0 = STM32F042, CANable 2.0 = STM32G431); the same design underlies many clones (DSD TECH SH-C30G/SH-C31A, Innomaker USB-CAN, Waveshare USB-CAN-A, Jhoinrch, and other slcan/gs_usb boards). Firmware is written over the STM32 built-in USB DFU bootloader with `dfu-util` (`dfu-util -d 0483:df11 -a 0 -R -s 0x08000000:leave -D <fw.bin>`); put the board in DFU mode first (CANable 1.0: BOOT jumper then re-plug USB; CANable 2.0/clones: double-tap RESET after plugging in — it enumerates as USB `0483:df11`). Two interchangeable firmwares are offered: **candleLight** (native gs_usb / SocketCAN, appears as a `can0` netdev) and **slcan** (serial-line CAN, appears as `/dev/ttyACM*`). Each `.qfw` auto-runs device info, then prepare (install dfu-util, download the `.bin`, confirm DFU mode), a summary, one "Are you sure?" gate, then the flash.
