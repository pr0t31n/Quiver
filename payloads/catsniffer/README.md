# CatSniffer v3

The CatSniffer v3 (Electronic Cats / LilyGo) is a multi-band RF sniffer built around a TI CC1352P7 radio (2.4 GHz + sub-1 GHz) sitting behind a Microchip SAMD21 USB bridge. Firmware is flashed to the CC1352P7 over its serial ROM bootloader through the SAMD21 bridge using the community-standard `cc2538-bsl` flasher (the same CC-radio serial-bootloader path used by the Sonoff / LilyGo Zigbee dongles) — no XDS110/JTAG probe is involved. Each `FIRMWARE -` payload runs unattended: device info → prepare (clone cc2538-bsl, download/verify the CC1352P7 `.hex`) → summary → a single "Are you sure?" → flash. Three firmwares are offered: **Sniffle** (NCC Group BLE 5 sniffer, Bluetooth Rx), **CatSniffer multiprotocol** (Electronic Cats Zigbee/802.15.4 + sub-GHz sniff), and **SmartRF 802.15.4 Zigbee sniffer** (TI-style packet sniffer, Zigbee Rx).
